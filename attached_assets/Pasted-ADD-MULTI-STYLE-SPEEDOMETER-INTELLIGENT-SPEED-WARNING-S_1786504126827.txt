9. ESCALATING WARNING

Create three warning levels.

LEVEL 1 — CAUTION

User approaches limit.

Example:

“Approaching speed limit.”

Use subtle visual/audio indication.

⸻

LEVEL 2 — WARNING

User exceeds limit.

Example:

“Speed limit exceeded. Please slow down.”

Use stronger visual warning and optional sound.

⸻

LEVEL 3 — SEVERE

User remains significantly above the configured limit.

Example:

“SLOW DOWN.”

Use stronger but controlled warning.

Do not create dangerous or distracting flashing effects.

10. IMPORTANT GPS RELIABILITY RULE

Never trigger a strong warning from unreliable GPS data.

Before issuing a warning:

Check:

GPS accuracy
Speed confidence
Recent location updates
Speed smoothing

If GPS accuracy is poor:

Show:

GPS SIGNAL WEAK

and avoid making strong speed-limit claims.

Never fabricate speed.

12. SPEED ALERT RESET

When the driver slows below the configured reset threshold:

Reset the warning state.

Example:

Limit = 60

Driver reaches 65:

WARNING

Driver slows to 57:

Return to NORMAL.

If driver later reaches 61:

Trigger a new warning.

Do not continuously repeat alerts while the driver remains in the same state.
